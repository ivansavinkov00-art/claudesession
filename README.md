# Культура шитья — прототип главной

> **v2 в работе.** Главная перестраивается под новую структуру: план, контракт разметки и порядок работ — в `PLAN-v2.md`, задача — в `PROMPT.md`. Картинки уже переехали в слоты `assets/img/img-01…13.webp` (фото v1, ставшие ненужными, — в `assets/img/_v1/`). Этот README будет переписан в конце v2.

Статичный прототип одной страницы: `index.html` + `styles.css` + `script.js`, без фреймворков и CDN. Всё собрано так, чтобы перенести в Tilda Zero Block: размеры шрифтов заданы в px по брейкпоинтам Тильды, анимация одна, эффектов при прокрутке нет.

## Как открыть

- Двойной клик по `index.html` — работает и с диска (спрайт логотипа встроен в страницу).
- Или через локальный сервер (порт 5507 выбран под этот проект):

```bash
python -m http.server 5507 --bind 127.0.0.1
```

Затем открыть http://127.0.0.1:5507/

## Перенос в Тильду

- Каждая секция = отдельный Zero Block. Размеры для 1200 / 960 / 640 / 480 / 320 выписаны в `DESIGN.md`.
- Шрифты Cormorant и IBM Plex Mono есть в Google Fonts внутри Тильды.
- Окна расчёта и прайса делаются попапами Тильды со встроенной формой. Подсказку «меньше 300 ед. → экспериментальный цех» можно оставить текстом под полем.
- Лента справа («Рассчитать стоимость») — закреплённый элемент Zero Block, видимый с 960 px; ниже 960 — фиксированная кнопка внизу экрана.

## Скрипты (нужен Node 18+ и `npm i`)

| Команда | Что делает |
|---|---|
| `npm run shots` | Скриншоты для сдачи в `screenshots/` (сервер на 5507 должен быть запущен) |
| `npm run review` | Скриншоты на всех брейкпоинтах в `.impeccable/review/` |
| `npm run e2e` | 13 проверок интерактива: окна, Esc, фокус, ошибки форм, согласие, подсказка, меню |
| `npm run assets` | Пересобрать `price-demo.pdf` и `og.jpg` |
| `node tools/logo.mjs` | Заново векторизовать машинку из `materials/logo.jpg` |
| `node tools/img.mjs <src> <out.webp> <longSide>` | Сжать фото в WebP |
