# Культура шитья — прототип главной, v3

Статичный прототип одной страницы: `index.html` + `styles.css` + `v3.css` + `script.js` + `v3.js` + три изолированных модуля в `modules/`. Без фреймворков, CDN и сборки, всё локально. Собрано так, чтобы переехать в Тильду: обычные экраны — Zero Block, три интерактивных модуля — HTML-блоки T123 (см. «Перенос в Тильду»).

Задача v2 — в `PROMPT.md`, тексты — в `materials/texts.md`, код-план и контракт разметки — в `PLAN-v2.md`, итоговый отчёт — в `REPORT-v2.md`. Слой v3 («плотная ткань»: шрифты Playfair + Onest, тёмные секции, ткань на первом экране, бегущая строка, scroll-анимации): план — `PLAN-v3.md`, отчёт — `REPORT-v3.md`, правила — раздел «v3» в `DESIGN.md`.

## Как открыть

- Двойной клик по `index.html` работает и с диска.
- Или через локальный сервер (порт 5507 выбран под этот проект):

```bash
python3 -m http.server 5507 --bind 127.0.0.1
```

Затем http://127.0.0.1:5507/. Добавьте `?slots` к адресу (`http://127.0.0.1:5507/?slots`), и на каждой картинке появится бирка с номером слота.

### Замена картинок

1. Положите файлы в `incoming/`, номер слота — в начале имени: `03.png`, `07-platye.jpg`.
2. Напишите в сессию Claude Code: «Новые картинки в incoming».
3. `node tools/incoming.mjs --dry` покажет план (кадр, размер, предупреждения), `node tools/incoming.mjs` поставит картинки: обрежет под пропорции слота с учётом безопасной зоны, сожмёт в WebP, запишет `img-NN.webp.json`, снимет `data-placeholder` в `index.html`, удалит оригинал из `incoming/`.
4. Дальше вручную: посмотреть картинки (руки и пальцы, игла и лапка, молнии и пуговицы, нет ли текста и логотипов, единый фон и свет в серии 04–09), обновить `CREDITS.md` и таблицу выше, снять скриншоты: `node tools/shots.mjs v2 --only=portfolio`.

## Перенос в Тильду

**Обычные экраны** (первый экран, производство, основатель, шов, финал, подвал) — Zero Block, по одному на экран. Размеры для брейкпоинтов 1200 / 960 / 640 / 480 / 320 выписаны в `DESIGN.md`. Шрифты Cormorant и IBM Plex Mono есть в Google Fonts внутри Тильды. Лента справа («Рассчитать стоимость») — закреплённый элемент Zero Block, видимый с 960 px; ниже 960 px — фиксированная кнопка внизу экрана. Вылет фото экрана 2 к краю окна в Zero Block делается штатно: элемент можно вытянуть за пределы сетки.

**Три модуля** — каждый вставляется HTML-блоком T123. У каждого свой префикс (`kc-carousel`, `kc-tasks`, `kc-calc`), свои цветовые токены на корне и ни одной глобальной зависимости, поэтому CSS и JS переносятся как есть.

1. В блок T123 вставьте разметку модуля из `index.html` (корень с `data-kc-carousel`, `data-kc-tasks` или `data-kc-calc`).
2. Ниже вставьте содержимое `modules/kc-имя.css` в `<style>` и `modules/kc-имя.js` в `<script>`.
3. Пути картинок (`assets/img/img-NN.webp`) замените на адреса загруженных в Тильду файлов.
4. Карточки и строки ведут на квиз ссылками `href="#raschet"`. Чтобы они работали, сам квиз должен стоять на странице в блоке с `id="raschet"` (якорь Тильды). Ссылка с предвыбором несёт `data-calc-direction` (`wb`, `brand`, `opt`, `sample`), `data-calc-item` (`hoodie`, `sweatshirt`, …) или `data-calc-nonstandard`.
5. Кнопка «Скачать прайс» в состоянии успеха квиза открывает окно `#price` через `data-open="price"`. В Тильде замените её ссылкой на попап прайса.

**Квиз на внутренних страницах.** На главной квиз стоит блоком в `#raschet`. На внутренних страницах тот же квиз откроется попапом Тильды: кнопки «Рассчитать стоимость» ведут на `#popup:название`, а внутри попапа стоит тот же T123-блок. Предвыбор через `data-calc-*` в таком случае придётся заменить скрытыми полями формы или отдельными попапами по направлениям.

**Квиз штатной формой-квизом Тильды.** Модуль повторяется формой-квизом Тильды: те же четыре шага и поля (таблица полей — `PLAN-v2.md`, раздел 4.4). Что придётся упростить:

- подсказка «Партии меньше 300 ед.» со сменой направления — статичным текстом под полем количества (условный показ в форме-квизе ограничен);
- «Сколько моделей» для образца — отдельным вопросом с пометкой «только для образца»;
- панель «Ваш проект», строка-итог и мерная лента — не переносятся (в квизе Тильды есть свой индикатор прогресса);
- миниатюры изделий — картинки в вариантах ответа;
- ошибки — штатные сообщения Тильды с текстами из `materials/texts.md`;
- отправка — заявки на почту управляющей и в Telegram-бот (в коде модуля оставлен `// TODO: отправка (Тильда: форма-квиз → почта + Telegram)`).
